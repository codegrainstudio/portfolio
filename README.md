# Muhammad Khalid Portfolio

## Open offline in Windows

1. Extract the ZIP.
2. Open the extracted folder in VS Code using **File > Open Folder**.
3. Double-click `index.html` in File Explorer to preview the site in your browser. Save changes in VS Code and refresh the browser.

The site uses plain HTML, CSS, and JavaScript. All assets are local.

## Edit your portfolio

- `index.html` contains your introduction, project cards, and About section. Duplicate an entire `<article class="project">` block to add a project.
- Place your own screenshots, notebook files, or resume in a new `assets` folder. Use relative paths such as `assets/plantdoc-results.png` in links and image sources.
- `styles.css` contains colors, layouts, and responsive styles.
- `portfolio.js` contains the theme switch and animated hero illustration.

Before sharing publicly, review the project descriptions, add your verified project links, and choose which contact details you want visitors to see.

## Host later

Upload `index.html`, `styles.css`, `portfolio.js`, and any assets you added to your hosting provider's website root. Use a static website configuration. No build command, server runtime, or API key is required.
