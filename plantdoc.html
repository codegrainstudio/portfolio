Project overview

The Colab notebook covers dataset preparation, training, and evaluation. It compares YOLOv8n with YOLO11n on the same detection task.

Dataset preparation

The Colab workflow prepares PlantDoc for object detection. The input is a plant image, and the detection task associates disease labels with regions of that image.

Model comparison

YOLOv8n and YOLO11n are trained and evaluated on the same task. Comparing the two lightweight models examines how they localize the disease in images.

Evaluation

The notebook brings preparation, training, and evaluation together so the steps for each model can be followed in one place.
