Multi-agent order management

A team demo showing how specialized agents coordinate product, inventory, order, and delivery tasks.

  • AutoGen
  • Microsoft Agent Framework
  • Tool use
E-COMMERCE / SIMULATED WORKFLOW
ProductCatalog agent InventoryStock agent OrderOrder agent DeliveryDelivery agent

Project overview

The workflow uses simulated orders to demonstrate sequential execution, parallel tasks, conditional routing, and tool use. The presentation covers AutoGen and Microsoft Agent Framework.

Agent responsibilities

The Product agent handles catalog information, the Inventory agent checks availability, the Order agent handles the order, and the Delivery agent handles delivery tasks.

Workflow patterns

The demo shows sequential execution where tasks depend on each other, parallel execution for independent work, and conditional routing when the next action depends on an earlier result.

Demonstration

The team uses simulated orders to show how agents exchange information and invoke tools. The presentation covers both AutoGen and Microsoft Agent Framework.
