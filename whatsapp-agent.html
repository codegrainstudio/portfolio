Project overview

The agent handles customer conversations, captures order details, and sends orders to the business’s point-of-sale (POS) system, helping staff manage incoming requests in one workflow.

Customer conversation

The customer starts a WhatsApp conversation to ask a question or place an order. The agent answers enquiries and collects the order details in the same conversation.

Order handoff

The agent sends the captured order to the business point-of-sale system so staff can manage it within their order workflow.
